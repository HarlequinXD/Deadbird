# FSM actions

Generated by `tools/list_actions.py` from `engine/fw/actions.c`. Each is a framework API call
(`engine/fw/fw.h`). Use `do` for once-on-entering (in order; Wait / MoveTo hold the list) and `every`
for every tick. Sense actions raise their event; the state's `on EVENT state` lines pick it up.


## Flow

| action | arguments | what it does |
|---|---|---|
| `Wait` | *ticks* | pause the do-list (60 ticks = 1 s) |
| `WaitRandom` | *min* *max* | pause a random time |
| `SendEvent` | *event* *target* | raise an event: self, player, all, enemies, owner |
| `Goto` | *state* | switch state now |
| `IfRandom` | *percent* *event* | raise the event this often |
| `IfTimeInState` | *ticks* *event* | raise once the state has run this long |

## Move

| action | arguments | what it does |
|---|---|---|
| `MoveForward` | *speed* | walk the way it faces |
| `ChasePlayer` | *speed* | turn to the player and walk at them |
| `FleePlayer` | *speed* | walk away from the player |
| `FacePlayer` | *rate* | turn toward the player (rate a tick, 0 = at once) |
| `Turn` | *rate* | turn every tick (4096 = full circle) |
| `Wander` | *speed* | stroll about, turning at walls |
| `MoveTo` | *x* *z* *speed* | walk to a point (do: waits until there) |
| `Teleport` | *x* *z* | jump to a point |
| `Jump` | *speed* | jump if on the ground |
| `Stop` | - | stand still |
| `Rise` | *amount* | move up (flyers) |
